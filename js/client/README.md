# @mustache-react/client

Browser runtime for mustache-react: mounts and hydrates the React pages and islands Spring renders, with useServerContext and useSpringForm.

Part of [mustache-react](https://github.com/inho-team/mustache-react), which lets Spring MVC applications render
React pages and islands from controllers and Mustache views. Use it through the mustache-react Gradle or Maven
plugin; see the [documentation](https://inho-team.github.io/mustache-react/).

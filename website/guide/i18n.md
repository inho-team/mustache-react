# 다국어 (i18n)

::: v-pre

메시지는 Spring의 `MessageSource`, 곧 `messages.properties`에서 옵니다. React 페이지, island, Mustache 템플릿이 모두 같은 파일을 씁니다.

## 1. 메시지 파일

```properties
# src/main/resources/messages.properties (기본 언어)
orders.title=주문 목록
orders.summary={0} / {1}건
orders.status.PAID=결제 완료
```

```properties
# src/main/resources/messages_en.properties
orders.title=Orders
orders.summary={0} of {1}
orders.status.PAID=Paid
```

## 2. 설정

```properties
# React에 내려보낼 메시지: 키, 접두어 패턴(orders.*), 또는 * (전부)
mustache-react.context.messages=app.name,nav.*,orders.*

# ?lang=en 으로 언어를 바꾸고 쿠키에 저장합니다
mustache-react.i18n.param=lang
mustache-react.i18n.locales=ko,en
# 사용자가 고르기 전 언어. 없으면 브라우저의 Accept-Language를 따릅니다
mustache-react.i18n.default-locale=ko

# messages.properties가 영어가 아닌 언어라면 꼭 끄세요. 켜져 있으면 서버 OS가 영어일 때
# 한국어 요청에 messages_en.properties가 나갑니다.
spring.messages.fallback-to-system-locale=false
```

| 설정 | 기본값 | 설명 |
|---|---|---|
| `mustache-react.context.messages` | 없음 | 페이지에 쓸 메시지. 여기 적은 것만 HTML에 들어갑니다 |
| `mustache-react.i18n.param` | 없음 | 언어를 바꾸는 요청 파라미터. 없으면 `Accept-Language`만 따릅니다 |
| `mustache-react.i18n.locales` | 없음 | 제공하는 언어 목록. 언어 선택 메뉴에 씁니다 |
| `mustache-react.i18n.default-locale` | 없음 | 처음 방문했을 때 언어 |
| `mustache-react.i18n.cookie-name` | `locale` | 선택한 언어를 저장하는 쿠키 |
| `mustache-react.i18n.cookie-max-age` | `365d` | 쿠키 유지 기간 |

직접 `localeResolver` 빈을 등록했다면 그대로 쓰고, `?lang=` 파라미터만 붙입니다.

## 3. React에서

```tsx
import { localeHref, useMessages, useServerContext } from '@mustache-react/client';

export default function OrderList({ orders, total }: PageProps<'orders/OrderList'>) {
  const { t } = useMessages();
  const { i18n } = useServerContext();
  return (
    <>
      <nav>
        {i18n?.locales.map((lang) => <a key={lang} href={localeHref(lang)}>{lang}</a>)}
      </nav>
      <h1>{t('orders.title')}</h1>
      <p>{t('orders.summary', orders.length, total)}</p>
      {orders.map((o) => <span key={o.id}>{t(`orders.status.${o.status}`)}</span>)}
    </>
  );
}
```

- `t(key, ...args)`는 `{0}`, `{1}`을 Java `MessageFormat`처럼 채웁니다. 숫자는 요청 locale로 포맷되고(`1234` → `1,234`), `''`는 작은따옴표 하나입니다.
- 내려보내지 않은 키는 키 그대로 보여서 빠진 메시지를 바로 알 수 있습니다.
- `localeHref('en')`은 현재 주소에 `?lang=en`을 붙인 링크입니다. 언어를 바꾸면 페이지를 새로 불러옵니다.

## 4. Mustache 템플릿에서

```handlebars
<html lang="{{mr.lang}}">
<title>{{#mr.t}}dashboard.title{{/mr.t}}</title>
<p>{{#mr.t}}orders.summary shown total{{/mr.t}}</p>   {{! 인자는 model 경로 }}
```

`{{#mr.t}}`는 HTML 이스케이프해서 씁니다. 같은 페이지의 island는 `useMessages()`로 같은 언어의 메시지를 받습니다.

## 5. 페이지 제목

`@ReactPage`의 `title`에 메시지 키를 쓰면 요청 언어의 제목이 됩니다. 키가 없으면 문자열 그대로 씁니다.

```java
@ReactPage(value = "orders/OrderList", title = "orders.title")
```

검증 메시지(`@NotBlank(message = "{required.customer}")`, `Errors.rejectValue`)도 같은 `MessageSource`로 요청 언어에 맞춰 나옵니다.

## 한글이 깨질 때

Spring Boot의 Mustache 뷰는 charset 없이 `text/html`을 보내서, 요청 언어가 한국어면 서블릿 컨테이너가 ISO-8859-1을 고릅니다. mustache-react는 Mustache 뷰에 `text/html;charset=UTF-8`을 붙여 이 문제를 막습니다. `spring.mustache.servlet.content-type`을 직접 지정했다면 그 값을 씁니다.
